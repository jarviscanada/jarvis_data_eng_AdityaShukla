**Linux  Cluster Monitor Project ** [[GitHub](https://github.com/jarviscanada/jarvis_data_eng_AdityaShukla/tree/develop/tree/master/linux_sql)]: The Linux Cluster Monitoring Agent is a Bash-scripted MVP designed to help the Linux Cluster Administration team at Jarvis automate server monitoring. It collects hardware specs and real-time resource usage data from Linux nodes, storing it in a PostgreSQL database running in a Docker container. Scripts (host_info.sh and host_usage.sh) capture static and dynamic data, respectively, with host_usage.sh running every minute via crontab. The system supports automated data logging, centralized storage, and performance analysis, significantly reducing manual monitoring. Git and Docker were used for version control and containerized deployment, ensuring portability and maintainability.
